# ImmoAnalyse
ImmoAnalyse est une application Python capable d'importer plusieurs
fichiers immobiliers, de contrôler leur qualité, de corriger les anomalies identifiables, d'analyser les
données exploitables et de produire des fichiers propres accompagnés d'un rapport de qualité. Le projet
utilise trois formats obligatoires : CSV, Excel et JSON.
